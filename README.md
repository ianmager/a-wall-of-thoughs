# a-wall-of-thoughts

This project is a public message wall where people who sign in can post short text. Messages will show up oldest first. The wall is readable by anyone. I will weed out inappropriate messages.

## Tools

- **Next.js** (App Router), **React**, **TypeScript**, **Tailwind CSS**
- **Supabase** (Postgres, Google sign-in, Row Level Security)
- **Vercel** (hosting)
